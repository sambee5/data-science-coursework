# data-science-coursework

The units are theoretical, offering specific notes on each topic. Each unit culminates in a project that explores the covered concepts.

While I tended to lean into my personal interests, such as swimming, I occasionally explored unfamiliar topics like astronomy and traffic patterns. Ultimately, I applied everything I learned to conduct a school-wide research project centered on the impact of natural intelligence and memorization on academic performance.

Course content can be found at [https://github.com/thedarredondo/data-science-fundamentals](https://github.com/thedarredondo/data-science-fundamentals)
